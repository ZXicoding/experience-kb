# 个人经验知识库（线上同步）

> 存放踩坑记录、项目经验、简历素材等长期复用内容。
> 通过 GitHub 私有仓库实现多设备同步。

## 目录结构

```
经验知识库/
├── README.md            ← 本文件
├── 索引.md              ← 总目录（先看这个）
└── 本地模型部署/         ← 各项目经验，一个项目一个子目录
    ├── 踩坑记录与经验总结.md
    ├── 简历项目经验总结.md
    ├── 兼容性报告.md
    └── 鸿蒙手机连接说明.md
```

## 多设备使用

1. **首次**：`git clone <仓库地址>`
2. **记录**：直接在对应目录加/改 .md 文件
3. **同步**：`git add . && git commit -m "..." && git push`
4. **其他设备拉取**：`git pull`
