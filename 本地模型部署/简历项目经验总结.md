## 一、可直接粘贴进简历的项目描述（推荐版）

### 项目名称
**本地多模态大模型 H5 应用** — 零依赖的端侧 AI 助手（图片理解 + 对话 + 图像处理 + 多设备访问）

### 项目描述（一段话版）

> 独立设计并实现了一套**完全本地化、零外部依赖**的多模态大模型 H5 应用：基于 Node.js 原生模块搭建 HTTPS 反向代理服务，对接本地 Ollama 推理引擎，支持多模态图片理解（qwen2.5vl 系列）、流式对话、图像处理（缩放/裁剪/水印/拼图/压缩）与语音交互。前端采用像素风游戏化 UI，实现模型动态切换与手机端自动轻量化调度（按 UA 识别设备，自动切换 3B/7B 模型）。自建 CA 证书体系解决移动端 HTTPS 信任问题，实现双端口（HTTP/HTTPS）+ 二维码扫码 + 短地址跳转的多设备接入方案，覆盖 iOS/Android/鸿蒙全平台。

### 量化成果（可选的数字，按实际情况填写）

- 覆盖 **7 个本地模型**、**3 个多模态视觉模型**的运行时调度
- 支持 **3 类终端**（桌面 / iOS / Android / 鸿蒙）零配置接入
- 手机端通过轻量模型调度，推理内存占用 **6GB → 3.3GB**，响应更流畅
- 全链路**零第三方依赖**（仅 Node.js 内置模块 + 系统 Pillow + Core Image）

## 三、项目亮点（面试/简历 bullet 点，按需选用）

### 架构与工程能力
- **零依赖架构**：仅用 Node.js 内置模块（https/http/fs/crypto）实现完整反向代理 + 鉴权 + 流式转发，无 npm install，降低部署门槛
- **自建 CA 证书体系**：用 OpenSSL 生成带 SKI/AKI 的 CA 根证书 + 服务器证书链，解决 iOS/Android/鸿蒙多平台 HTTPS 信任问题
- **双端口容灾**：HTTP(8080) + HTTPS(8443) 并存，HTTP 端口作为无证书兜底，保证任何浏览器可用

### 多模态与调度
- **多模态接入**：图片（base64 传输）、视频（浏览器端 Canvas 抽帧）、语音（Web Speech API）三类输入
- **智能模型调度**：按 User-Agent 识别设备类型，手机端自动切换轻量模型（3B），桌面端用标准模型（7B），兼顾性能与体验
- **模型能力标注**：从 Ollama `/api/tags` 读取 capabilities，前端展示「多模态/纯文本」标签

### 工程细节（体现踩坑深度）
- **流式兼容**：从 `fetch getReader` 迁移到 `XHR onprogress`，解决夸克等国产浏览器流式读取不兼容问题
- **数据格式对齐**：处理 data URL 与纯 base64 的差异，修复多模态图片传输的编码错误
- **证书信任闭环**：macOS 钥匙串（GUI/命令行双路径）+ 移动端描述文件（.mobileconfig/.cer）+ JS Blob 下载兜底

## 六、如果面试追问「最有挑战的部分」，可以这样答

1. **移动端证书信任链路**：自签名证书在 iOS/Android/鸿蒙上的信任策略完全不同（iOS 要 SKI/AKI 扩展、鸿蒙浏览器拦截证书下载），最终用「自建 CA + 多格式分发 + HTTP 兜底」三层方案闭环。

2. **国产浏览器流式兼容**：夸克等浏览器对 `fetch` 流式响应支持不完整，通过迁移到 `XHR onprogress` + 非流式兜底，保证所有浏览器可用。

3. **模型资源调度**：24GB 统一内存下，按设备自动切换模型（手机 3B / 桌面 7B），平衡性能与体验。
