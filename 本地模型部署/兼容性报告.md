# H5 本地模型 · 多设备兼容性报告

> 检查日期：2026-10-14 · 目标：确保各种手机系统/浏览器都能连接使用

## 一、连接方式总览

| 方式 | 地址 | 适用场景 | 证书要求 |
|------|------|---------|---------|
| **HTTP（推荐）** | `http://192.168.1.159:8080/go` | 任何手机/浏览器，最省心 | 无需证书 |
| **HTTPS（加密）** | `https://192.168.1.159:8443/go` | 装证书后，更安全 | 需装证书 |
| **扫码** | 顶栏 📱 按钮的二维码 | 手机免输入 | 指向 HTTP 端口 |

## 二、各系统兼容性

| 系统 | HTTP 访问 | HTTPS 访问 | 证书安装方式 |
|------|----------|-----------|-------------|
| **iOS (iPhone/iPad)** | ✅ 直接可用 | 需装描述文件 | `/cert/ios`（.mobileconfig） |
| **Android** | ✅ 直接可用 | 需装 CA 证书 | `/cert`（.crt） |
| **鸿蒙 HarmonyOS** | ✅ 直接可用 | 需装 CA 证书 | `/cert`（.crt） |
| **macOS 桌面** | ✅ 可用 | ✅ 已信任证书 | 已自动配置 |

## 三、浏览器兼容性

| 浏览器 | HTTP | HTTPS（未装证书） | HTTPS（装证书后） |
|--------|------|------------------|------------------|
| Safari | ✅ | ⚠️ 有「继续」选项 | ✅ |
| Chrome / Edge | ✅ | ⚠️ 有「继续」选项 | ✅ |
| 夸克 / UC / 360 | ✅ | ❌ 强制拦截 | ✅（装证书后） |
| 微信内置浏览器 | ✅ | ❌ 强制拦截 | ✅（装证书后） |
| 华为浏览器 | ✅ | ⚠️ 视版本而定 | ✅ |

**结论**：HTTP 端口（8080）是所有浏览器都能用的万能方案。

## 五、手机安装证书步骤（HTTPS 用，可选）

### iPhone/iPad
1. Safari 打开 `http://192.168.1.159:8080/setup`
2. 点「下载 iOS 描述文件」
3. 设置 → 通用 → VPN与设备管理 → 安装
4. 设置 → 通用 → 关于本机 → 证书信任设置 → 开启信任

### Android/鸿蒙
1. 浏览器打开 `http://192.168.1.159:8080/setup`
2. 点「下载证书（.crt）」
3. 设置 → 搜索「证书」→ 安装证书 → CA 证书 → 选择文件
