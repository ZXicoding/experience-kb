# 鸿蒙手机连接说明

## 方案一：用 HTTP 端口（最快，推荐先用这个）

手机浏览器（任何浏览器，包括夸克）直接打开：

```
http://192.168.1.159:8080/go
```

或扫二维码（顶栏 📱 按钮里的二维码已指向 HTTP 端口）。

> HTTP 端口不加密、不校验证书，所以**不会出现「网络错误」**，任何浏览器都能用。
> token 鉴权仍然有效，只是传输不加密（局域网内可接受）。

---

## 方案二：装证书后用 HTTPS（更安全，一劳永逸）

如果想让手机用加密的 HTTPS（`https://192.168.1.159:8443`），需要先装证书。

### 第一步：下载证书

手机浏览器打开（用 HTTP 端口，无需先信任就能下载）：

```
http://192.168.1.159:8080/cert
```

下载得到 `ollama-h5-ca.crt` 文件。

### 第二步：安装证书

鸿蒙不同版本的路径略有差异，常见入口：

| 鸿蒙版本 | 证书安装路径 |
|---------|-------------|
| HarmonyOS 4（EMUI 兼容） | 设置 → 安全 → 更多安全设置 → 加密和凭据 → 安装证书 → CA 证书 |
| HarmonyOS NEXT（纯血鸿蒙） | 设置 → 安全与隐私 → 证书管理 → 从存储安装 |
| 部分版本 | 设置 → 生物识别和密码 → 安全 → 凭据存储 → 安装证书 |

选择刚下载的 `.crt` 文件，按提示完成安装。

### 第三步：验证

装完后，手机浏览器访问：

```
https://192.168.1.159:8443/go
```

不再有证书警告即成功。

---

## 重要提示

1. **夸克浏览器对自签名证书拦截很严**，即使装了证书也可能仍打不开 HTTPS。
   - 建议手机用 **华为浏览器 / Chrome / Edge** 访问 HTTPS。
   - 或者直接用**方案一（HTTP 端口）**，夸克也能正常用。

2. **HTTP 端口（8080）是最省心的选择**，手机端无证书烦恼，适合日常使用。

3. 证书有效期到 2036 年，装一次长期有效。
